API Documentation

All endpoints are prefixed with /api and return JSON. Responses include an X-API-Version header.

GET /api/health

Health check. Returns service status and number of indexed fonts.

curl {{ request.host_url }}api/health
{
  "status": "ok",
  "font_count": {{ font_count }}
}

POST /api/identify

Upload a font file to find the closest open-source matches. Rate limited: 10 requests/minute per IP.

curl -X POST -F "file=@MyFont.ttf" {{ request.host_url }}api/identify

Accepts: TTF, OTF, WOFF, WOFF2. Max file size: 10 MB.

Success (200)

{
  "matches": [
    {
      "name": "Roboto-Regular.ttf",
      "family": "Roboto",
      "distance": 0.0832,
      "metric_distance": 0.042,
      "perceptual_distance": 0.11,
      "score": 61,
      "score_breakdown": { "metric": 78, "perceptual": 52 },
      "license_id": "Apache-2.0",
      "license_label": "Apache 2.0",
      "download_url": "/api/font-file/Roboto-Regular.ttf",
      "google_fonts_url": "https://fonts.google.com/specimen/Roboto"
    }
  ],
  "cached": false
}

download_url serves the font file directly. google_fonts_url is null for fonts not on Google Fonts.

Error (400)

{ "error": "Unsupported font format", "type": "UnsupportedFontError" }

Error (413)

{ "error": "File too large. Maximum size is 10 MB." }

GET /api/browse

Search and browse fonts in the corpus with optional filters.

curl "{{ request.host_url }}api/browse?q=roboto&category=sans-serif&page=1&per_page=20"

Parameters

  • q — search query (optional, filters by family name)
  • category — sans-serif, serif, or mono (optional)
  • page — page number, default 1
  • per_page — results per page, default 40, max 100
{
  "fonts": [
    { "family": "Roboto", "category": "sans-serif", "license_id": "Apache-2.0" }
  ],
  "total": 142,
  "page": 1,
  "per_page": 20,
  "pages": 8
}

GET /api/fonts/<id>

Retrieve metadata for a font by database ID.

curl {{ request.host_url }}api/fonts/1

Success (200)

{
  "id": 1,
  "file_hash": "abc123...",
  "name": "Roboto-Regular.ttf",
  "family": "Roboto",
  "subfamily": "Regular",
  "units_per_em": 2048,
  "license_id": "Apache-2.0",
  "source": "ofl/roboto/Roboto-Regular.ttf"
}

Error (404)

{ "error": "Font not found" }

GET /api/font-file/<name>

Download a font file from the corpus. Returns the binary font file with the correct MIME type.

curl -O {{ request.host_url }}api/font-file/Roboto-Regular.ttf

Responses are cached for 24 hours via Cache-Control headers.

Error (404)

{ "error": "Font not found in DB" }

POST /api/scores

Submit a 1–5 quality rating for a match. One rating per IP per font pair.

curl -X POST -H "Content-Type: application/json" \
  -d '{"query_font":"MyFont.ttf","match_font":"Roboto-Regular.ttf","score":4}' \
  {{ request.host_url }}api/scores

Success (200)

{
  "average_score": 3.8,
  "vote_count": 12,
  "saved": true
}

Error (400)

{ "error": "score must be integer 1-5" }

POST /api/report

Report a bad match. One report per IP per font pair.

curl -X POST -H "Content-Type: application/json" \
  -d '{"query_font":"MyFont.ttf","match_font":"BadMatch.ttf"}' \
  {{ request.host_url }}api/report
{ "reported": true }
